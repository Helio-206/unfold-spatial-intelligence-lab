# Unfold — landing page

Static, dependency-free page. Open `index.html` or serve the folder with any static host.

- Built on the design system in `../design-system/` (light theme, Geist / Geist Mono, self-hosted in `fonts/`).
- `index.html` holds markup, styles and a small script for the folding cube and the before/after slider. Both respect `prefers-reduced-motion`.
