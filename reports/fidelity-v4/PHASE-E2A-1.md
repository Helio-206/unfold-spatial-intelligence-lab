# V4 E2-A.1 — assembly research, experimental and incomplete

## Implementation

`src/universal-spatial/parametric-e2a/assembly.ts` adds a three-body synthetic assembly and a bounded hinge-tree solver. Each body has a rigid, parent-relative position and XYZ rotation, with unit scale. Each directed joint has two local anchor points and two unit axes. The root and all orientations are fixed. For each parent-child joint the solver analytically computes the child's position that coincides with the parent anchor; it rejects missing/duplicate joints, disconnected/cyclic hierarchy, axis disagreement, correction beyond the caller's bound and non-finite or oversized values. It does not infer orientations, optimise a hinge angle, detect collisions, calculate forces or certify engineering validity. Input is not mutated. `proposeAssembly` validates inferred V2 geometry and transforms on a plan copy, checks existing identity/hierarchy and refuses non-unit scale. It does not bind a source revision or authorise application.

The beam uses the existing V2 loft with variable sections. An isolated Three.js prototype `offset-beam.ts` supports linearly offset rectangular sections (2–32, 128 vertices maximum) with indexed caps and computed normals. A test checks that each indexed edge has two adjacent faces and normals are finite; it does not prove absence of self-intersections. It is not expressible as the existing V2 loft and is not emitted as a V2 proposal. The bucket uses four existing box solids (floor, back and two sides), with a mounting block and an open mouth. The solids intersect/overlap and are not boolean-unioned; the bucket is therefore **not a single watertight manifold**. A physical hinge pin, attachment clevis, thickness continuity and collisions are not established. This does not satisfy the requested validated structural shell/topology. No new shared V2 operator was added.

## Synthetic experiments

Criteria were frozen in `e2a-1/CRITERIA.md` before running the benchmark. Two distinct parametric assemblies are generated by the same code as the candidate; they are **not independent geometry implementations**. The reference supplies all anchors and rotations; only two local translations are perturbed. Beam width is also perturbed by 20% and remains uncorrected: there is no silhouette fitting, geometric reconstruction from image evidence or independent fitting input. Four views are labelled fitting views for comparison only; the solver uses none of their pixels. Four other calibrated views are held out. These experiments demonstrate conditional closure, not recovery from incomplete images.

| Fixture | Joint gaps before → after (plan units) | Four comparison views IoU before → after | Four held-out views IoU before → after | Width error |
|---|---|---|---|---|
| long-arm | 0.60 / 0.50 → 0 / 2.2e-16 | 0.734 → 0.969 | 0.773 → 0.965 | 20% → 20% |
| compact | 0.60 / 0.50 → 0 / 4.4e-16 | 0.611 → 0.955 | 0.600 → 0.966 | 20% → 20% |

Each final scene: 7 meshes, 4,524 position vertices, 1,540 triangles using the V2 compiler. After 10 warmups, 20 solver calls in one Node process: long-arm median 0.070 ms, range 0.062–0.155 ms; compact median 0.077 ms, range 0.052–0.214 ms. Heap deltas across 20 calls were +701,960 and +655,648 bytes; these are noisy live-heap changes, not peak or retained memory. Exact run in `e2a-1/metrics.json`. Results do not predict browser/GPU performance. Reproduce with `npx tsx scripts/benchmark/v4-e2a-assembly.ts`.

## Visual inspection

`e2a-1/assembly-comparison.png` is a local Chromium/SwiftShader capture: original saved plan; synthetic reference, perturbed and corrected chain; side and three-quarter views. Red markers indicate supplied anchor positions. The synthetic parts read as two straight arms and a rectangular open box; it is not a convincing excavator bucket or full excavator. The before image shows an open gap at the first hinge, and the corrected image closes it visually at this scale. The bucket and arm intersect at their mounting area; box plate overlaps are visible and no seam/manifold verification was performed. An image cannot certify hidden collisions or mechanical validity. There is no independent human review or licensed external reference in this experiment. Camera framing differs for the saved plan and synthetic assembly; no visual fidelity comparison between them is justified.

## Tests and integration boundary

Dedicated tests cover joint closure after perturbation, preservation of rotations and input, bounds and incompatible axes, missing/duplicate joints, and inferred non-mutating V2 proposals with identity/source retention and non-unit-scale rejection. The dedicated and related test run passed 13 tests across three files before the offset test was added; the updated assembly test file passed 5 tests. Build passed (existing contact-variable and bundle-size warnings). The default `npm test` was run twice: the first run overlapped the build and had 11 failures (10 timeouts and one performance guard). The second run had 2,485 passed / 7 failed: six 5-second timeouts in existing hierarchy, lifecycle, buried-component and bucket-width tests, and the existing Foundry build-time guard measured 4,163 ms against 4,000 ms. Its final second overlapped one short focused test; neither result establishes the root cause. With `npm test -- --maxWorkers=4 --testTimeout=60000`, 155 files / 2,492 tests passed. This explicitly configured run does not erase the default failures.

For any future integration, E1 must bind each candidate to the actual source bytes/hash, revision, component identity and human review; E0 must atomically apply an authorised batch and provide exact undo. Existing hypotheses must not become confirmed relations automatically. The solver does not check collisions or overconstraints beyond a parent-child tree; loops, unknown axes/anchors and non-unit scale require explicit support or refusal.

**NO-GO for experimental integration.** Required remaining work: independently generated reference assemblies and actual fitting from designated evidence, V2-compatible offset beam and independently verified watertight bucket topology, non-invented joint evidence for the saved plan, collision and pivot validation, and independent visual review. Current held-out IoU is conditional on known joints/rotations and does not meet the reconstruction evidence criterion.
