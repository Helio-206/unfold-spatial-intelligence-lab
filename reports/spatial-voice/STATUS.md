# Spatial Voice — partial functional integration

Base: PR #28 snapshot `fb1f892cdf773a51f61a3f5c745efb2f11fca5d3`. The branch is independent of Cloud. The universal plan supplies the selected ID and the source data; no excavator registry is used. Local text separates plan provenance from general facts conditional on the component label. Microscope and lungs plans are hand-authored reproductions, not Meta output. No Meta calls were made.

The workspace inspector now exposes Explain, transcript, local source, browser speech controls, device voices and speed. Space, selection, plan revision and geometry upgrades invalidate the explanation and cancel narration. Dictation cancels speech and late recognition events are discarded. No voice action moves the camera or edits geometry.

The no-synthesis fallback passed. Browser console/page errors were empty in these scenarios. Screenshots in the ignored `reports/spatial-voice/evidence/` directory show the interface; run `node tests/e2e/spatial-voice.pw.mjs` with Vite on port 5195 to reproduce.

No physical Safari/iOS, screen-reader, real pointer picking, network-late-response, live Meta, or leak profiling evidence. The Meta universal explanation endpoint is not implemented.
