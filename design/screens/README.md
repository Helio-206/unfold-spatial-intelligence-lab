# Design screens (work in progress)

Source files of two Design canvases, exported as `.dc.html` + `canvas.json`. Not wired into the app.

- `concept-a-lab/` — central interactive four-bar figure (drag to rotate, explode steps), light/dark, desktop + mobile.
- `concept-b-instrument/` — "O instrumento": cube-net home, Desdobrar workspace (evidence sheet, certainty lens, change preview), electrical screen.

All numbers, file names and measurements in the screens are illustrative sample data. Logos are referenced as uploaded
assets (`/_blob/<id>`) in the canvases; the originals are in `design-system/logos/`.
